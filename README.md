# 🛠️ Sistema de Gestión para Ferretería

Proyecto de software en desarrollo orientado a la gestión de una ferretería.

La aplicación busca centralizar y facilitar tareas relacionadas con la gestión de productos, stock, ventas y otras operaciones comerciales.

## 💻 Tecnologías utilizadas

- Python
- SQLite
- CustomTkinter
- Git
- GitHub
- Visual Studio Code

## ⚙️ Funcionalidades

Actualmente el proyecto se encuentra en desarrollo e incorpora progresivamente:

- Gestión de productos
- Control de stock
- Registro y consulta de información
- Interfaz gráfica de usuario
- Persistencia de datos mediante SQLite

## 🗂️ Estructura del proyecto

- `main.py` → punto de inicio de la aplicación
- `gui/` → interfaz gráfica
- `database/` → conexión y operaciones con la base de datos

## 🔒 Privacidad de los datos

La base de datos utilizada por la aplicación no se incluye en este repositorio para preservar la confidencialidad de la información.

Los archivos de datos y otros archivos locales sensibles son excluidos mediante `.gitignore`.

## 🚧 Estado del proyecto

**En desarrollo.**

El proyecto continuará incorporando nuevas funcionalidades y mejoras a medida que avance su implementación.
